The LoopVòng lặp

Six Stages, Six ArtifactsSáu giai đoạn, sáu artifact

Every stage commits one version-controlled file that the next stage reads. Agents do the work; you stay above the loop at two gates. Mỗi giai đoạn commit một file vào git để giai đoạn sau đọc. Agent làm việc; bạn đứng trên vòng lặp ở hai cổng duyệt.

InstallCài đặt

Pin Your Stack in One LineGhim stack của bạn trong một dòng

Pick your runtimes and copy the command. The release tag lives in the URL, so the same version always produces the same scaffold. Chọn runtime rồi sao chép lệnh. Tag phiên bản nằm ngay trong URL, nên cùng một phiên bản luôn cho ra cùng một bộ khung.

Short URL, always the latest release on main. For a build that can never change, switch to the pinned tag. URL ngắn, luôn lấy bản mới nhất trên main. Muốn kết quả không bao giờ đổi thì chuyển sang bản ghim theo tag.

The tag is immutable: this exact command produces this exact scaffold, today and next year. Tag là bất biến: đúng lệnh này luôn cho ra đúng bộ khung này, hôm nay hay sang năm.

The script pins versions only (.nvmrc, .python-version, .tool-versions, manifests). Install runtimes with mise install, nvm or asdf. Script chỉ ghim phiên bản (.nvmrc, .python-version, .tool-versions, manifest). Cài runtime bằng mise install, nvm hoặc asdf.

WorkflowQuy trình

Your First Feature in Three CommandsTính năng đầu tiên chỉ với ba lệnh

From idea to a reviewed local commit. Agents loop on their own within bounded rounds; the decisions stay yours. Từ ý tưởng tới một commit đã được review trên máy. Agent tự lặp trong số vòng giới hạn; quyết định vẫn thuộc về bạn.

  1. > /intent Add password reset via email

    Claude asks what an analyst would ask, then writesClaude hỏi như một analyst, rồi viết intent/reset-password.md

  2. > /spec intent/reset-password.md

    Requirements, design, acceptance criteria and flagged risks inYêu cầu, thiết kế, tiêu chí chấp nhận và rủi ro được đánh dấu trong specs/reset-password.md

  3. > /feature specs/reset-password.md

    The planner writesPlanner viết plans/reset-password.md

  4. Gate 1 — You approve the planCổng 1 — Bạn duyệt plan

    Approve, request changes, or cancel. Nothing is coded before this.Duyệt, yêu cầu sửa, hoặc hủy. Chưa có dòng code nào trước bước này.

  5. coder → tester (≤ 3) → reviewer (≤ 2)

    Runs on its own branch. Every phase appends a row to the plan's pipeline log.Chạy trên nhánh riêng. Mỗi pha ghi thêm một dòng vào pipeline log của plan.

  6. Gate 2 — You approve the commitCổng 2 — Bạn duyệt commit

    A conventional commit lands on feat/reset-password, with a ready-to-paste PR description. You push.Một conventional commit trên feat/reset-password, kèm mô tả PR sẵn để dán. Bạn tự push.

FAQ

Frequently Asked QuestionsCâu hỏi thường gặp

Something missing?Chưa thấy câu trả lời? Ask on GitHubHỏi trên GitHub

Is this an official Anthropic product?Đây có phải sản phẩm chính thức của Anthropic?
No. It is an independent, MIT-licensed starter that follows the structure of Anthropic's published AI-Native SDLC Playbook.Không. Đây là starter độc lập, giấy phép MIT, đi theo cấu trúc của AI-Native SDLC Playbook mà Anthropic đã công bố.
Does it install Node, Python or Go?Nó có cài Node, Python hay Go không?
No. It only pins versions: .nvmrc, .python-version, .tool-versions and the matching manifest. Install runtimes with mise, nvm or asdf. This keeps the one-liner dependency-free.Không. Nó chỉ ghim phiên bản: .nvmrc, .python-version, .tool-versions và manifest tương ứng. Cài runtime bằng mise, nvm hoặc asdf. Nhờ vậy lệnh một dòng không phụ thuộc gì.
Is it safe to run twice?Chạy lại lần hai có an toàn không?
Yes. Existing files are skipped unless you pass --force (-Force on Windows).Có. File đã tồn tại sẽ được bỏ qua, trừ khi bạn dùng --force (-Force trên Windows).
Can the agents push or deploy on their own?Agent có tự push hay deploy được không?
No. git push is denied in settings.json and blocked again by the guard-bash hook. The pipeline commits locally only after Gate 2, and production deploys need a named approval.Không. git push bị cấm trong settings.json và bị hook guard-bash chặn thêm lần nữa. Pipeline chỉ commit trên máy sau Cổng 2, và deploy production cần người duyệt có tên.
Why is the version tag in the URL?Vì sao tag phiên bản nằm trong URL?
A tag never changes, so v0.1.0 gives every teammate and every CI run the exact same scaffold. Upgrade by changing the tag.Tag không bao giờ đổi, nên v0.1.0 cho mọi thành viên và mọi lần chạy CI cùng một bộ khung. Muốn nâng cấp, chỉ cần đổi tag.
Does it work on Windows?Có chạy trên Windows không?
Yes — PowerShell 5+ or pwsh 7+. The PowerShell script writes the same files as the bash one, byte for byte (UTF-8, LF).Có — PowerShell 5+ hoặc pwsh 7+. Script PowerShell tạo đúng các file như bản bash, giống từng byte (UTF-8, LF).
