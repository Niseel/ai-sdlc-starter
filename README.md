# AI-Native SDLC Starter

One command scaffolds a project that follows Anthropic's AI-Native SDLC playbook
(Plan → Design → Build → Test → Deploy → Maintain), with the Claude Code agents,
skills and guardrail hooks that run the loop. macOS, Linux and Windows.

Một lệnh dựng khung dự án theo AI-Native SDLC của Anthropic (Plan → Design →
Build → Test → Deploy → Maintain), kèm agent, skill và hook bảo vệ của Claude Code.

Work in progress — the scripts, the landing page and the docs land next.
Đang phát triển — script, landing page và tài liệu sẽ được đưa lên tiếp theo.
